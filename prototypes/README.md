# Interface Prototypes

Use this directory for interface mockups, user flows, and materials supporting prototype walkthroughs.

For each prototype, identify the user scenario, the related requirements, the source or editing tool, and how to open the exported result. Include the states needed to understand the scenario, such as missing data, errors, or an unavailable estimate.

Label demonstration records as synthetic. A static mockup must not imply that a model has been trained, an integration is connected, or a displayed interaction is implemented.

Record agreed, de-identified walkthrough findings in the project documentation and link the resulting changes to their tasks. Do not store private participant notes here.
