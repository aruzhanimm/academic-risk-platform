# Architecture Diagrams

This directory is reserved for the system context, use case, and component diagrams.

When a diagram is added:

- Put its editable source in `sources/` and a readable SVG, PNG, or PDF export in `exports/`.
- Use matching names so the source and export can be located together.
- Document the editing tool or generation command required to reproduce the export.
- Update the source and export in the same change and inspect labels, arrows, boundaries, and legibility.
- Link the diagram to the relevant architecture description and requirements.

The source and export directories will be created with their first files. Diagram content must distinguish planned components from implemented ones.
