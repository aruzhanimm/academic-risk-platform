# Frontend

This directory is reserved for the student-facing application interface.

Planned responsibilities include workload entry, personal history, explanations of available estimates, and controls over personal records. Keep empty, loading, error, and unavailable-estimate states understandable.

Add the selected framework configuration, dependency manifest, package-manager lockfile, and setup, run, and test commands with the first executable implementation.

Use [prototype materials](../../prototypes/README.md) to guide the interface. Prototype screens and synthetic examples must remain distinguishable from functioning features and real records.
