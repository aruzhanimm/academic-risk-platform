# Project Documentation

This directory contains the project document set. Linked documents are available for review; a link does not mean that the deliverable or its proposed implementation has been accepted.

| Area | Expected contents |
| --- | --- |
| [Project proposal](01_project_proposal.md) | Problem, users, aim, objectives, expected outcomes, and scope. |
| [User interviews and evidence of relevance](02_user_interviews.md) | Nine questionnaire submissions, five anonymised interview records, limitations and effects on requirements. |
| [Literature review](03_literature_review.md) | Critical synthesis, a publication analysis table, and references. |
| [Existing systems](04_existing_system_comparison.md) | Comparable systems assessed against shared criteria with sources. |
| [Technology decisions](05_technology_comparison.md) | Alternatives, selection criteria, and reasons for the proposed choices. |
| [Requirements](06_requirements_specification.md) | Functional and non-functional requirements, priorities, and acceptance criteria. |
| [Architecture](07_architecture.md) | Components, data flows, interfaces, access boundaries, and links to diagrams. |
| [User experience](08_ux_prototype.md) | Synthetic interaction prototype, editable sources, captures, recorded interpretation issues and further walkthrough checks. |
| [Verification and evaluation](09_verification_evaluation.md) | Acceptance checks, data/protocol gates, baselines, metrics, and evaluation conditions. |
| [Project management](10_project_management/README.md) | Responsibilities, milestones, risks, dependencies, and YouTrack links. |
| [Supervisor feedback](11_supervisor_feedback.md) | Review status and decisions requested for the next stage. |

Use descriptive filenames and relative links between published materials. Record a document's scope, sources, and review information where appropriate. Add links here as the documents are published.

Supporting material belongs in [research](../research/README.md), [diagrams](../diagrams/README.md), and [prototypes](../prototypes/README.md). Follow the [contribution workflow](../CONTRIBUTING.md) when submitting changes.
